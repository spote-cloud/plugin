# Spote usage skill

Spote is a persistent Markdown notebook for durable human and agent knowledge — not for scratch notes or short-lived conversation state.

- **Search before creating.** Check for an existing note on the subject; update it instead of creating a duplicate.
- **Tags** are inline `#hashtags` — use a few meaningful ones, not many generic ones.
- **Prefer Mermaid** for anything relational: architecture, workflows, sequences, dependencies, state transitions, timelines.
- **Link deliberately.** Use `relate_notes` when two notes have a durable semantic relationship, and `get_related` to follow those links when researching a topic.
